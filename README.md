## Lo que hago

- **vCISO y vGRC** — liderazgo de seguridad y el sistema que hace que las decisiones se cumplan: inventario, políticas, registro de riesgos y evidencia.
- **GRC para pymes** — ISO/IEC 27001:2022 y NIST CSF 2.0, análisis de brechas, inventario de activos y riesgos, y priorización por exposición.
- **Auditoría de IA** — auditar todo lo que rodea a la IA: gobierno, entrada, proceso, salida, decisión y evidencia.
- **Evidencia y reportes ejecutivos** — evidencia simple, fechada y recuperable, y reportes de una o dos páginas en lenguaje de negocio.

- **[Weltcomm-grc](https://github.com/weltcomm/Weltcomm-grc)** — Laboratorio de práctica GRC de código abierto: ENS, ISO/IEC 27001 y continuidad de negocio.
